# Page files and route map

This repository began with a rendered WordPress/WooCommerce homepage export. The remaining page files below are source-page snapshots collected from the linked public site on 2026-11-14. The original page text, markup, product images, prices and layout were retained; populated inline CSS/JavaScript was moved to `assets/css/page-extracts/` and `assets/js/page-extracts/`. Links to captured content pages point to local files; uncaptured destinations and live commerce actions remain pointed at the original website.

## Folder layout

- `home.html` — original homepage capture; captured content-page links point to local files, while dynamic commerce links remain live.
- Root HTML files — the main information, policy, promotion, and editorial pages.
- `brand-archives/` — individual brand archive pages.
- `categories/` — product-category pages, retaining category nesting.
- `products/` — individual product detail pages.
- `commerce/` — cart and account page snapshots.
- `assets/css/page-extracts/` and `assets/js/page-extracts/` — deduplicated inline assets shared across page snapshots.

The live homepage also links to `/contact.html`, which returned a 404 during this capture. That link now resolves locally to `contact.html`, captured from the working `/contact-us/` page.

## Dynamic commerce routes

The cart, account and lost-password files are rendered source snapshots. They retain the live site’s WordPress/WooCommerce forms and external runtime references. A static HTML file cannot provide a working cart, account authentication, inventory, checkout, or server-side form handling by itself; those functions require the original WordPress/WooCommerce backend.
